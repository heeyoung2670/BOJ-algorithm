# BOJ-algorithm

백준 온라인 저지([acmicpc.net](https://www.acmicpc.net)) 문제 풀이 모음. 학부 시절 자료구조·알고리즘을 공부하며 풀었던 문제들을 문제 번호 단위로 기록해 둔 저장소입니다.

## 저장소 구조

```
.
├── #<문제번호>            # 일반 문제 풀이 (Python / C++)
├── 삼성_SW-test/          # 삼성 SW 역량 테스트 기출 (Python)
│   └── C++/              # 동일 문제군을 C++로 재작성한 풀이
└── README.md
```

- 파일명은 BOJ 문제 번호와 1:1로 대응됩니다. 예: `#2580` → <https://www.acmicpc.net/problem/2580>
- 각 파일 상단에는 주석으로 **문제 제목**과 **적용 알고리즘**을 남겨 두었습니다.
